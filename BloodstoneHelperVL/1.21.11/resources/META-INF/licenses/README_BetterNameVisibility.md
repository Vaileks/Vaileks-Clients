BloodHelper supplies its own module/configuration UI, disabled by default, with a serverSafeMode gate.
The 26.3 integration targets name-tag submission specifically; it does not change all text rendering.
Text color overrides copy text fragments instead of modifying shared entity name components.
No YACL or separate Better Name Visibility installation is required. No original assets are bundled.
